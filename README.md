# 📚 BUNKO SPACE

**A Place Where Stories Begin**

BUNKO SPACE adalah website online bookstore yang dibuat sebagai project untuk persiapan Ujian Sertifikasi Kompetensi (USK).

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## 👤 Actors

### Admin
- Manage Categories
- Manage Books
- View Registered Users
- Manage Orders

### User
- Register & Login
- Browse Books
- Search Books
- Add to Cart
- Checkout
- Contact Admin

## 📌 Project Status

🚧 Currently in development.
